# Boarding Pass to Launch — Countdown Lock Screen & Interactive Generator

Built for the **Handshake AI Skills Studio × Google** November 2026 Challenge (*"Your Deadline, Your Design: Create a Countdown Lock Screen"*).

## What’s Included
- **Swiss-Aviation Boarding Pass Lock Screens** in two finishes (*Midnight OLED* & *Warm Archival Paper*), engineered around real **iOS 18**, **Android 15**, and **4K Desktop 16:9** safe zones (`Top 28%` clock zone, `Bottom 16.2%` icon/home-bar zone, `72px` side margins).
- **Interactive Web Simulator & Customizer**: preview live OS clock overlays, toggle visual Safe Zone guides, customize your own deadline & 6 chronological milestones (with automatic `T-XX` recalculation), and export pixel-perfect PNGs (`1290×2796`, `3840×2160`, `1600×1000`).
- **Google Gemini Workflow Pack**: 1-click copy prompts for backward planning, multimodal lock-screen design, and scheduled daily reminders.
